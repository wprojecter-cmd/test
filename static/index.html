Developer playground

GraphQL Request Lab

Учебная панель для изучения GraphQL: имя операции, тело запроса, variables и формат ошибок. Запрос обрабатывается только локальным демонстрационным endpoint.

Безопасный режим: запрос не отправляется в Render Dashboard или другой внешний сервер. API-ключ не создаётся. Не вводи сюда реальные cookie, токены или данные сессии.

Параметры теста

Готов к локальному тесту

Кнопка отправляет данные только на /api/demo-mutation этого приложения. Сервер возвращает смоделированную GraphQL-ошибку валидации.

Окно логов

[готово] Локальная демонстрация запущена.
[защита] Внешние запросы отключены.
[защита] Секреты не запрашиваются и не логируются.
